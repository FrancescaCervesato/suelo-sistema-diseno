Radio Button

Control de selección única dentro de un grupo. Estados: default, seleccionado y deshabilitado. Indicado para opciones mutuamente excluyentes.

Estados
default, seleccionado y deshabilitado
💡
Tip de uso
Si el grupo tiene 5 opciones o más, evaluá reemplazarlo por un Select — el radio button funciona mejor con pocas opciones visibles a la vez.
