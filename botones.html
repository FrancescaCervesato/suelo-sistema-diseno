Botones

Componentes de acción del sistema SUELO. Los botones son el medio principal de interacción del usuario con la interfaz.

Boton default
Átomo

Botón principal del sistema para acciones primarias, secundarias y terciarias. Componente más utilizado en toda la interfaz.

Propiedades
Propiedad Tipo Valores Descripción
Variante Variant Primario | Default | Soft | Link | Compra Define el estilo visual del botón
Estado Variant Activo | Hover | Focus | Deshabilitado Estado de interacción actual
Tamaño String default Tamaño del botón
Con Icono Boolean true | false Muestra icono junto al texto
Uso recomendado
  • Usar variante Primario para la acción principal de la pantalla
  • Soft para acciones secundarias sin competir visualmente
  • Link para navegación inline
  • Compra exclusivamente para flujos transaccionales

Boton segmentado
Átomo

Grupo de botones conectados visualmente para alternar entre opciones mutuamente excluyentes. Similar a un toggle group.

Propiedades
Propiedad Tipo Valores Descripción
Segmentos Instance 2-5 segmentos Cantidad de opciones
Seleccionado Variant Índice del activo Segmento actualmente seleccionado
Uso recomendado
  • Usar para filtros rápidos (ej: Vista Lista / Grilla)
  • Máximo 5 opciones, textos cortos
  • No usar como navegación principal

Partes botón segmentado
Átomo

Sub-componentes internos que componen cada segmento individual del botón segmentado. No se usa directamente.

Uso recomendado
  • Componente interno — no instanciar directamente
  • Modificar solo desde el componente padre Boton segmentado
