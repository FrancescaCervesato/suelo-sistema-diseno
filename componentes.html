Documentación y referencia de los 41 componentes oficiales del sistema de diseño SUELO. Organizados por Atomic Design: Átomos → Moléculas → Organismos.

Átomos

15

Boton segmentado
Grupo de botones para alternar entre opciones mutuamente excluyentes.

Checkbox

Check
Indicador visual de verificación/confirmación simple.
Toggle
Interruptor on/off para activar o desactivar configuraciones.
Spinner
Indicador de carga animado para procesos en curso.
Tag
Etiqueta visual para categorizar o etiquetar contenido.
Chips
Elementos compactos para filtros, selección o visualización de datos.
Logo primary
Logotipo principal de SUELO en sus variantes oficiales.
Stickers
Elementos decorativos e ilustrativos del sistema.
Ilustraciones
Set de ilustraciones para estados vacíos y comunicación visual.

Titulo
Componente tipográfico para encabezados con estilos predefinidos.
Trend numérico
Indicador de tendencia con valor numérico y dirección (positivo/negativo).

Input

Stepper
Indicador de progreso por pasos para flujos multi-etapa.
Date picker
Selector de fecha con calendario interactivo.
Tabs

Partes tab
Sub-componentes internos que componen cada pestaña individual.

Desplegable menu

Item desplegable

Items de menu

Columnas

Paginado de grilla
Control de paginación para navegar entre páginas de datos.
Drag and drop (uploader)

Notas frames

Empty state
