Tooltip Molécula

Información contextual flotante que aparece al hacer hover sobre un elemento de la interfaz.

Propiedades

Propiedad Tipo Valores Descripción
Posición Variant Top | Bottom | Left | Right Posición relativa al elemento
Contenido String Texto libre Texto informativo del tooltip

Uso recomendado

  • • Usar para información complementaria no esencial
  • • Máximo 2 líneas de texto
  • • No incluir acciones interactivas dentro del tooltip

Toast advertencia Molécula

Notificación temporal tipo snackbar para mensajes de advertencia, confirmación o error.

Propiedades

Propiedad Tipo Valores Descripción
Tipo Variant Success | Warning | Error | Info Tipo semántico del mensaje
Acción Boolean true | false Incluye botón de acción

Uso recomendado

  • • Usar para confirmaciones de acciones completadas
  • • Duración: 3-5 segundos para info, persistente para errores
  • • Posicionar en la parte inferior de la pantalla

Empty state Molécula

Pantalla de estado vacío con ilustración y acción sugerida cuando no hay datos para mostrar.

Propiedades

Propiedad Tipo Valores Descripción
Ilustración Instance Componente de ilustración Imagen descriptiva del estado vacío
Acción Boolean true | false Incluye CTA para resolver el estado

Uso recomendado

  • • Siempre incluir una acción para resolver el estado vacío
  • • Usar ilustraciones del set oficial de SUELO
  • • El texto debe ser empático y orientado a la solución
