Formularios y Selección

Componentes para entrada de datos, selección de opciones y controles de formulario.

Select
Molécula

Selector desplegable para elegir una opción de una lista predefinida. Incluye búsqueda en listas largas.

Propiedades
PropiedadTipoValoresDescripción
VarianteVariant Default | Outlined | Filled Estilo visual del selector
EstadoVariant Default | Open | Error | Disabled Estado actual
PlaceholderString Texto libre Texto guía cuando no hay selección
Uso recomendado

• Usar para listas de 5+ opciones

• Para 2-4 opciones usar Radio buttons o Segmented

• Incluir siempre un placeholder descriptivo

Date picker
Molécula

Selector de fecha con calendario interactivo. Permite selección de día, mes y año.

Propiedades
PropiedadTipoValoresDescripción
TipoVariant Single | Range Selección simple o rango de fechas
FormatoString DD/MM/YYYY Formato de visualización de la fecha
Uso recomendado

• Usar formato DD/MM/YYYY (estándar local)

• Deshabilitar fechas no válidas visualmente

• Para rangos, mostrar ambas fechas claramente

Selector múltiple
Molécula

Control combinado de selección múltiple con chips de selección y búsqueda integrada.

Propiedades
PropiedadTipoValoresDescripción
PlaceholderString Texto libre Texto cuando no hay selección
Max selecciónNumber Ilimitado Máximo de opciones seleccionables
Uso recomendado

• Usar cuando el usuario necesita seleccionar múltiples opciones de una lista

• Los chips seleccionados deben ser removibles individualmente

• Incluir acción 'Limpiar todo' para más de 3 selecciones
