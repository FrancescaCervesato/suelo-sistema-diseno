Input (Campo de Texto)

El componente Input permite a los usuarios ingresar, editar y buscar datos en campos de texto estructurados. Soporta etiquetas, iconos y textos de ayuda de manera nativa.

Uso del Componente

Cuándo utilizar
  • • Para el ingreso de datos simples de una sola línea (nombres, contraseñas, correos).
  • • En formularios de registro, inicio de sesión y configuración.
  • • Campos de búsqueda rápida o filtrado interactivo de grillas.
Cuándo evitar
  • • Si el usuario requiere ingresar textos largos, utilizar un  en su lugar.
  • • Si las opciones de respuesta están predefinidas y son fijas, use el componente .
  • • Para la selección de rangos de fechas o valores continuos, usar selectores numéricos dedicados.

Anatomía del Componente

1. Label / Etiqueta *
2. Icono Izq 3. Texto Placeholder / Input 4. Icono Der
5. Helper text / Texto descriptivo adicional

Elementos Clave:

  1. Texto descriptivo corto que indica qué debe ingresar el usuario en el campo. Obligatorio por accesibilidad.
  2. Delimita el área activa de interacción. Cambia su color según el estado (Error, Focus, Hover, Inactivo).
  3. Proporcionan claves visuales rápidas o disparan acciones adicionales (como borrar o ver contraseña).
  4. Información de soporte debajo del contenedor para dar formato o clarificar requisitos.

Buenas y Malas Prácticas (Do / Don't)

Prácticas Recomendadas
1. Incluya siempre etiquetas visibles La etiqueta orienta permanentemente al usuario incluso si el campo ya fue completado.
2. Use texto de ayuda descriptivo Guíe al usuario con formatos requeridos o explicaciones cortas bajo el campo.
Evitar estas prácticas
1. No oculte la etiqueta confiando en el Placeholder Al escribir, el placeholder desaparece y el usuario pierde el contexto del campo.
2. No use estados de error para mensajes informativos El color rojo y la señal de alerta están reservados estrictamente para bloqueos del flujo.

Lineamientos de Accesibilidad

Requisitos de Accesibilidad (WCAG 2.1 AA)
  • • El componente debe ser completamente enfocable mediante el tabulador (Tab) y mostrar un borde de enfoque altamente contrastante (Focus State).
  • • Los elementos descriptivos (Label y Helper Text) deben estar vinculados lógicamente con el input usando atributos de aria descriptivos.
  • • El borde del input y el texto de la etiqueta mantienen una relación de contraste mínima de 4.5:1 contra el fondo.
