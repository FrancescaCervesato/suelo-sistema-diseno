Empty State

Pantalla vacía cuando no hay contenido disponible. Incluye ilustración, título y descripción. Puede tener un CTA para guiar al usuario hacia la siguiente acción.

💡
Tip de uso
Diferenciá el copy según la causa: no es lo mismo "todavía no hay datos" que "tu búsqueda no arrojó resultados" — el CTA cambia en cada caso.
