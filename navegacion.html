Componentes para guiar al usuario a través de la interfaz y flujos multi-paso.

Tabs Molécula

Navegación por pestañas para organizar contenido en secciones dentro de una misma vista.

Propiedades

Propiedad Tipo Valores Descripción
Variante Variant Default | Underlined | Contained Estilo visual de las pestañas
Activo Variant Índice del tab activo Pestaña seleccionada

Uso recomendado

  • Usar para 2-7 secciones de contenido relacionado
  • El primer tab debe ser el más relevante
  • No anidar tabs dentro de tabs

Breadcrumb Molécula

Navegación jerárquica que muestra la ubicación actual del usuario dentro de la estructura de la aplicación.

Propiedades

Propiedad Tipo Valores Descripción
Niveles Instance 2-5 niveles Cantidad de niveles de profundidad
Separador String › | / | > Carácter separador entre niveles

Uso recomendado

  • Usar en páginas con más de 2 niveles de profundidad
  • El último nivel (actual) no es clickeable
  • Siempre incluir 'Inicio' como primer nivel

Stepper Molécula

Indicador de progreso por pasos para flujos multi-etapa lineales o no lineales.

Propiedades

Propiedad Tipo Valores Descripción
Pasos Number 2-7 Cantidad total de pasos
Paso actual Number 1-N Paso en el que se encuentra el usuario
Orientación Variant Horizontal | Vertical Dirección del stepper

Uso recomendado

  • Usar para flujos de 3-7 pasos
  • Mostrar etiquetas descriptivas en cada paso
  • Permitir navegación a pasos completados

Paginado de grilla Molécula

Control de paginación para navegar entre páginas de datos en tablas y grillas.

Propiedades

Propiedad Tipo Valores Descripción
Páginas Number Total de páginas Cantidad total de páginas disponibles
Actual Number Página actual Página actualmente visible

Uso recomendado

  • Usar para conjuntos de datos > 25 elementos
  • Mostrar siempre primera, última y páginas cercanas
  • Incluir selector de 'elementos por página'
