Guía de Uso Tipográfico
✅ CORRECTO
Usa notoSansH1Bold exclusivamente para encabezados principales de página y puntos de entrada de alto nivel en el dashboard, para reforzar una jerarquía visual correcta.
❌ INCORRECTO
No uses estilos de bajo peso como notoSansCaption para contenido de párrafo general, ya que compromete la legibilidad en pantallas industriales de baja resolución.

Espaciado (Spacing Scale)

SUELO maintains an incremental spatial grid computed directly from numeric tokens. These values control outer container margins, block relationships, and inner-element padding to produce unified and balanced UI layouts.
