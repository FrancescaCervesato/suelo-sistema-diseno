Tokens de Color

El sistema de diseño SUELO utiliza un modelo de dos capas para gestionar colores de manera eficiente. La capa primitiva define el universo de opciones de color, mientras que la capa semántica asigna significado y contexto para un soporte consistente de temas claros y oscuros.

Colores Primitivos
