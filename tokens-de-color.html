Colores

Paleta semántica y escalas de color relevadas 1:1 de las variables de Figma. Usar estos valores literalmente en cualquier implementación — no aproximar ni inventar tonos parecidos.

Nota técnica
Cada token está disponible como variable CSS en css/tokens.css (ej. var(--color-primario)). Fuente: página "Colores" del archivo Figma Sistema de diseño 1.0. La marca SUELO (wordmark, gradiente) es solo identidad de este sitio web y no forma parte del sistema de tokens documentado.
